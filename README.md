# Lua Script Collection (Educational & Experimental)

## Overview

This repository contains a collection of Lua scripts developed for **learning, experimentation, and technical exploration purposes**. The scripts demonstrate various mechanics such as movement control, targeting logic, rendering overlays, and general client-side manipulation concepts.

The primary goal of this repository is to **analyze, understand, and practice scripting techniques**, not to promote misuse in real environments.

---

## ⚠️ Important Notice

This project is strictly:

> **Educational and Experimental**

* These scripts are intended for **learning how systems work internally**
* They should be used in **controlled environments only** (e.g., private testing, sandbox setups)
* Using such scripts in real online games/services may violate terms of service and lead to penalties

---

## Repository Contents

### Core Scripts

* `AimBot.lua` → Target tracking and aiming logic (algorithmic study)
* `HumanAim.lua` → More natural/limited aiming simulation
* `ESP.lua` → Object/player visualization concepts
* `Optimization.lua` → Performance improvements and code efficiency

### Movement & Interaction

* `ClickTP.lua` → Click-based teleportation logic
* `Telelport.lua` → Direct teleport functionality
* `Dash.lua` → Fast movement mechanic
* `fly.lua` → Free-flight movement simulation
* `NoClip.lua` → Collision bypass concept

### Behavior / Utility

* `Ghost.lua` → Visibility/state manipulation
* `Stalk.lua` → Tracking/following logic
* `Jenga.lua` → Physics interaction example
* `Ball&Axe.lua` → Object interaction script

### Hub Scripts

* `Buba'sHub.lua`
* `Deha'sHub.lua`
  → Script loaders / UI hubs to manage multiple features
